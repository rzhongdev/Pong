# Pong

Java Pong game I made in high school. The ball has a random chance to speed up every time it's hit, so games get harder the longer they go. Has 1 player (vs CPU), 2 player, and a leaderboard that saves your best runs.

## How to run

```
javac -d bin src/*.java
java -cp bin Pong
```

Run it from the project folder, not from inside src or bin, or the leaderboard won't save properly.

## Controls

Player 1: W / S
Player 2: Up / Down arrows
